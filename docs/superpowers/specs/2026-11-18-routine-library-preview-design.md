# Routine library preview

The owner wants to see a routine's exercises before adding it to their personal list.

Add Details beside Add in the existing library. Tapping the routine name also opens a read-only sheet showing exercise names, available thumbnails, sets/reps or durations, and notes. The sheet offers Add and Close. Opening or dismissing it never imports the routine or custom exercises. Keep the existing direct Add shortcut.

Use the same plan-bundle reader for preview and import, so bundled custom exercise names and converted weights match the copy actually added. Reuse existing sheet, exercise-label, target-summary, and translated UI components; preserve prior changes to back navigation.

An inline expansion would make the catalog harder to scan on a phone; the existing sheet pattern fits this small change. Verify preview/cancel without mutation, successful import as a fresh copy, custom exercises, empty classes, and units. Implementation stays local and uncommitted.
